# Student Performance Analysis Dashboard 📊

An interactive Microsoft Excel dashboard built to explore student academic performance through summary metrics, charts, and filters.

## Project highlights

- Developed KPI cards showing **total students**, **average score**, and **top performers**
- Used Pivot Tables to summarise performance data
- Created bar, pie, and line charts for visual comparisons
- Added slicers for interactive exploration of the dashboard

## Tools and skills

**Microsoft Excel · Data Cleaning · Pivot Tables · Slicers · KPI Design · Data Visualisation**

## Explore the dashboard

**[Download the Excel workbook](<Project 1.xlsx>)**

1. Download the workbook from the link above.
2. Open it in Microsoft Excel.
3. Explore the dashboard, slicers, Pivot Tables, and supporting worksheets.

This is an academic/personal analytics project rather than a live database-connected dashboard.

## What I learned

How to turn spreadsheet data into clearer, interactive summaries so a reader can explore performance trends instead of reading individual rows.
